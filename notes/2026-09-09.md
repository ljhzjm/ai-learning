## 常用命令速查(今天实际用过的)

```powershell
uv add alembic                          # 安装
uv run alembic init alembic             # 初始化:alembic.ini + alembic\(env.py, versions\)
uv run alembic revision --autogenerate -m "描述"   # 对比模型与库,生成迁移草稿
uv run alembic upgrade head             # 升到最新
uv run alembic downgrade -1             # 回退一步
uv run alembic history                  # 版本链:ffc8… -> 560c… -> 8358… (head)
uv run alembic current                  # 当前版本 id,读库里的 alembic_version 表
docker exec -i pg-school psql -U postgres -d todo -c "\d todos"   # 看表结构验证迁移结果
```
