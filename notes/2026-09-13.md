## 晚间加餐 2 · 第 3 周·周二(Token 估算与计价)

### 加餐 5 行速记

1. **学了**:启发式估算(中按字数×系数、英按字符÷4)+ 实测校准——多段不同长度文本发 API 拿真实 usage,`statistics.linear_regression` 线性拟合,DeepSeek 中文拟合结果 **token ≈ 0.654×字数 + 3.31**(每字约 0.65 token、每消息固定开销约 3 token,校准系数已回填 estimate.py)
2. **计价公式**:成本 = prompt/1M×输入单价 + completion/1M×输出单价;**价格页单位是每百万 tokens,代码里除 1_000_000**
3. **核心坑(自己踩的)**:cost.py 真实调用 max_tokens 硬编码 100,和估算用的 max_out 对不上(自己注释都写了警告还是踩了);**短答案问题**输出预算用不满,预估误差能到 206%(「今天天气不错。」)——输出 token 估算天然不稳
4. **验收**:挑战 3 段新文本(开放式长答题,模型把 50 token 预算用满)误差 +0.5%/+2.4%/+2.2%,全部 < 20% 过关
5. **明天**:Prompt 基础:角色/指令/约束/few-shot,分类与信息抽取对比实验
