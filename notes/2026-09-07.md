## 常用命令速查(今天实际用过的)

```powershell
# 起 PG 容器(命名卷持久化)
docker run -d --name pg-school -p 5432:5432 -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=school -v pg-school-data:/var/lib/postgresql/data postgres:16-alpine
docker ps                              # 看到 pg-school Up
docker exec -it pg-school psql -U postgres -d school   # 进 psql

# 执行 SQL 文件(PowerShell,无 < 重定向)
Get-Content schema.sql | docker exec -i pg-school psql -U postgres -d school

# 被墙时拉镜像(替代 docker pull)
python D:\ITstudy\tools\pull_image.py library/postgres:16-alpine xxx.tar
docker load -i xxx.tar
```

psql 元命令:`\l` 库列表 · `\c 库名` 切换 · `\dt` 表 · `\d 表名` 结构 · `\di` 索引 · `\q` 退出
执行计划:`EXPLAIN`(只看不跑)/ `EXPLAIN ANALYZE`(真跑+耗时);Seq Scan=全表扫,Index Scan=走索引
SQLite→PG 差异:`INTEGER PRIMARY KEY`→`SERIAL PRIMARY KEY`、`REAL`→`NUMERIC(4,1)`、字符串单引号、未加引号标识符折小写
