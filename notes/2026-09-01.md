## 今日知识点

- uv 0.12 的 `uv init` 默认 **src 包布局**;运行入口 = `[project.scripts]` 定义的命令(`uv run <入口名>`)
- `uv add` 装依赖并自动更新 pyproject.toml + uv.lock;`uv tree` 看依赖树;uv.lock 锁版本保证可复现
- pydantic-settings:`SettingsConfigDict(env_file=".env")` 读配置;字段声明类型 = 自动校验,错误配置启动即报 ValidationError
- 配置优先级:**环境变量 > .env 文件 > 默认值**(生产环境用环境变量注入配置的原理)
- FastAPI:`@app.get/post` 装饰器定义接口;路径参数 `{name}`、查询参数(函数参数带默认值)、请求体(BaseModel 校验,类型错返回 422);`/docs` 自动生成交互式文档;`--reload` 改代码自动重启
- .env 不进 git、.env.example(占位模板)进;`git check-ignore <路径>` 验证忽略规则是否生效

## 常用命令速查(今天实际用过的)

```powershell
uv init <目录>                  # 建项目(src 布局)
uv add <包名>                   # 装依赖
uv run <入口名>                 # 运行项目(自动管理 .venv)
uv tree                         # 看依赖树
uv run uvicorn w1d4_fastapi_demo.main:app --reload   # 启动 FastAPI(热重载)
$env:DEBUG='false'; uv run w1d3-hello-uv             # 临时环境变量覆盖 .env
Remove-Item Env:DEBUG           # 清掉临时环境变量
git check-ignore <路径>         # 验证 gitignore 规则
python study.py next / sync / watch / finish         # 学习任务自动化
```
