## 常用命令速查(今天实际用过的)

```powershell
# 拉镜像 + 起容器
cd D:\ITstudy\tools
python pull_image.py library/redis:7-alpine redis-7-alpine.tar
docker load -i redis-7-alpine.tar
docker run -d --name redis-cache -p 6379:6379 redis:7-alpine

# redis-cli 常用
docker exec -i redis-cache redis-cli PING            # PONG
docker exec -i redis-cache redis-cli GET todos:list  # 看缓存内容
docker exec -i redis-cache redis-cli TTL todos:list  # 剩余秒数,-1 不过期,-2 不存在
docker exec -i redis-cache redis-cli EXISTS todos:list   # 写操作后应为 0(已失效)
docker exec -i redis-cache redis-cli FLUSHDB         # 清空 db0

# 限流验证(cmd,连打 15 发看状态码)
for /l %i in (1,1,15) do curl -s -o nul -w "%{http_code} " http://127.0.0.1:8000/todos
```

cache-aside 四步:请求→查 Redis→命中直接返回 / 未命中查 PG 写缓存(带 TTL)→返回;POST/PATCH/DELETE 改完库先删缓存,下次读重建。
