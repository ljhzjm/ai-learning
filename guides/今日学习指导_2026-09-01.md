## 🎯 先懂 3 个概念(2 分钟)

| 概念 | 一句话解释 |
|---|---|
| **虚拟环境** | 每个项目一套独立的 Python 依赖,互不污染(uv 自动管理 `.venv` 文件夹) |
| **pyproject.toml** | 项目的"身份证":名字、Python 版本、依赖清单全写在这里 |
| **.env** | 放配置和密钥的文件(如数据库地址、API Key),**绝不能提交到 git** |

uv 是新一代包管理器:一条命令干完 pip + venv + 锁版本的所有活,而且快几十倍。

> 💡 uv 0.12 新版默认生成 **src 包布局**(专业项目的标准结构):

> ```

> ├── pyproject.toml        # 项目身份证 + 入口点定义
> ├── src/
> │   └── w1d3_hello_uv/

## ⚙️ 第 2 步:pydantic-settings 管理 .env(40 分钟)

**① 新建 `.env` 文件**(在**项目根目录** `w1d3-hello-uv\` 下新建),写入:

```
APP_NAME=hello-uv
DEBUG=true
DATABASE_URL=postgresql://localhost:5432/mydb
```

**② 新建 `src\w1d3_hello_uv\config.py`**(注意:放进包里,和 `__init__.py` 同一层):

```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8")

    app_name: str
    debug: bool
    database_url: str

settings = Settings()
```

> 要点:pydantic 负责**校验类型**(debug 是 bool 不是 str,写错会报错),settings 负责**从 .env 读值**。

**③ 把 `src\w1d3_hello_uv\__init__.py` 改成**:

```python
from w1d3_hello_uv.config import settings

def main() -> None:
    print(f"app_name     = {settings.app_name}")
    print(f"debug        = {settings.debug}")
    print(f"database_url = {settings.database_url}")
```

> 因为整个项目是"一个包",所以 import 要用**包名前缀** `w1d3_hello_uv.config`,而不是裸的 `config`。

**④ 跑起来看效果**:

```powershell
uv run w1d3-hello-uv
```

**⑤ 做一个关键实验 —— 环境变量的优先级**(PowerShell):

```powershell
$env:DEBUG='false'; uv run w1d3-hello-uv
```

你会发现 DEBUG 变成了 false —— **系统环境变量 > .env 文件**。这就是生产环境的做法:代码不写死配置,部署时用环境变量注入,本地开发用 .env。

**⑥ 保护 .env 不进 git**:打开 `.gitignore`,加一行 `.env`,再新建一个 `.env.example`(内容同上但值用占位符如 `xxx`),它才是要提交的"模板说明书"。

# 🚀 加餐 · 第 1 周·周四:FastAPI 入门(2h)

> **任务**:路径/查询/请求体参数、Pydantic 校验、自动文档
> **验收**:写 3 个小接口,访问 /docs

## 🎯 先懂 3 个概念

| 概念 | 一句话解释 |
|---|---|
| **FastAPI** | Python 现代 Web 框架:把"URL 路径 + Python 函数"变成 HTTP 接口,Pydantic 负责校验 |
| **uvicorn** | ASGI 服务器 —— 真正"跑起来"的引擎,FastAPI 应用由它启动 |
| **/docs** | FastAPI 送的免费礼物:自动生成的接口文档网页(Swagger UI),还能直接在上面试接口 |

三种参数对照(HTTP 请求解剖):

- **路径参数**:写在 URL 路径里,`GET /hello/{name}` → 访问 `/hello/world`
- **查询参数**:URL 问号后面,`GET /items?skip=5&limit=3` → 一般有默认值
- **请求体**:POST 请求的 JSON 数据,配合 Pydantic 模型做校验

## 🛠️ 第 1 步:建项目 + 装依赖(10 分钟)


## ⚙️ 第 2 步:写 3 个接口(30 分钟)

新建 `src\w1d4_fastapi_demo\main.py`:

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

# 接口 1:路径参数 —— /hello/{name} 里的 {name} 会被捕获
@app.get("/hello/{name}")
def hello(name: str):
    return {"message": f"Hello, {name}!"}

# 接口 2:查询参数 —— ?skip=5&limit=3,不传就用默认值 0 和 10
@app.get("/items")
def list_items(skip: int = 0, limit: int = 10):
    all_items = list(range(100))
    return {"items": all_items[skip : skip + limit]}

# 接口 3:请求体 + Pydantic 校验
class Item(BaseModel):
    name: str
    price: float
    is_offer: bool = False

@app.post("/items")
def create_item(item: Item):
    return {"created": item.name, "price": item.price, "is_offer": item.is_offer}
```

(`__init__.py` 里 uv 生成的 `main()` 不用管,想清爽可以清空。)

## ▶️ 第 3 步:跑起来,访问 /docs(30 分钟)

```powershell

```

看到 `Uvicorn running on http://127.0.0.1:8000` 就成功了(终端会被占用,要敲别的命令就再开一个终端)。然后:

2. 开 `http://127.0.0.1:8000/items?skip=5&limit=3` —— 查询参数生效;再试试不带 `?` 参数访问,默认值生效


   点 Execute 看返回结果
4. **校验实验**:body 故意写错类型(`price` 填 `"abc"` 或 `name` 填 `123`)→ 返回 **422** 错误,这就是 Pydantic 在拦
5. 改一下 main.py 的返回文字并保存 → 终端自动重启(`--reload` 的作用),刷新页面看变化

## 🍰 加餐:把今天的 pydantic-settings 接进来(20 分钟)

新建 `src\w1d4_fastapi_demo\config.py`(和 hello-uv 项目一样):

```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8")

    app_name: str = "fastapi-demo"

settings = Settings()
```

在项目根新建 `.env`,写 `APP_NAME=我的第一个FastAPI`;`.gitignore` 规则仓库根已覆盖。

在 `main.py` 顶部加:

```python
from w1d4_fastapi_demo.config import settings

@app.get("/")
def root():
    return {"app": settings.app_name, "docs": "http://127.0.0.1:8000/docs"}
```

刷新 `http://127.0.0.1:8000/` —— 配置从 `.env` 进来了。以后 FastAPI 项目的数据库地址、密钥全走这个模式。
