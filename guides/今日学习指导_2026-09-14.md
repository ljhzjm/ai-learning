## 🎯 先懂协议:一个 POST + 三个词(15 分钟)

OpenAI 兼容的 chat 接口,就是一个 POST:

```
POST {base_url}/chat/completions
Headers: Authorization: Bearer <你的key>   Content-Type: application/json
Body:    {"model": ..., "messages": [...], "max_tokens": ...}
```

返回 JSON 三块:`choices[0].message.content`(回答正文)、`choices[0].finish_reason`(结束原因)、`usage`(token 统计)。

| 概念 | 一句话解释 | 今天要亲手验证的 |
|---|---|---|
| **messages** | 对话全文,每次请求**全量**提交 | 模型是**无状态**的:第 2 轮它不记得第 1 轮!"记忆"= 你把历史拼回 messages |
| **role** | `system` 定人设 / `user` 你 / `assistant` 模型 | 多轮顺序 `[sys, u1, a1, u2]`,逐条 append |
| **token** | 计量与计费的最小单位,**不是字符** | 中文 1 字≈1~2 token,英文 1 词≈1~2 token;`usage` 回给你三个数 |
| **max_tokens** | 只限制**输出**长度 | 设太小回答被拦腰截断,`finish_reason` 变成 `"length"` |

加餐:`temperature`(0~2,越高越发散;代码/翻译类任务喜欢调低)——今天不用,以后会讲。

## 📦 第 2 步:hello.py——发出人生第一个请求(30 分钟)

`src/w3d1_hello_llm/hello.py`(**手打**,不要复制粘贴):

```python
import httpx

from w3d1_hello_llm.settings import Settings


def main():
    s = Settings()
    r = httpx.post(
        f"{s.base_url}/chat/completions",
        headers={"Authorization": f"Bearer {s.api_key}"},
        json={
            "model": s.model,
            "messages": [
                {"role": "system", "content": "你是一位简洁的编程老师,回答不超过三行。"},
                {"role": "user", "content": "什么是 API?"},
            ],
            "max_tokens": 200,
        },
        timeout=60,  # 生成要几秒~几十秒,httpx 默认 5 秒会超时
    )
    r.raise_for_status()
    data = r.json()
    print(data["choices"][0]["message"]["content"])
    print("usage:", data["usage"])  # prompt_tokens / completion_tokens / total_tokens
```

跑:`uv run python -m w3d1_hello_llm.hello`。控制台看到回答 + usage 三个数字 = 验收线过了一半。

改两个地方各再跑一次,把现象记进笔记:
1. system 换成「你是东北话翻译,把用户的话翻译成东北话」→ 同样的问题,回答风格全变 → **人设来自 system**
2. `max_tokens` 改成 10 → 回答被截断,`finish_reason` 是 `"length"` → **max_tokens 是输出的硬上限**

> 今天用同步 httpx 保持简单;到第 3 周流式(SSE)那几天会需要异步,你的 asyncio 会派上用场。

## 📦 第 3 步:multi_turn.py——用 input() 做多轮对话(40 分钟)

写一个终端聊天循环,亲手制造"失忆现场":

```python
import httpx

from w3d1_hello_llm.settings import Settings


def main():
    s = Settings()
    history = [{"role": "system", "content": "你是简洁的助手,回答不超过两行。"}]
    print("输入 quit 退出。第一轮先告诉它你的名字。")

    while True:
        text = input("你: ").strip()
        if text.lower() == "quit":
            break
        history.append({"role": "user", "content": text})
        r = httpx.post(
            f"{s.base_url}/chat/completions",
            headers={"Authorization": f"Bearer {s.api_key}"},
            json={"model": s.model, "messages": history, "max_tokens": 200},
            timeout=60,
        )
        r.raise_for_status()
        answer = r.json()["choices"][0]["message"]["content"]
        print("AI:", answer)
        history.append({"role": "assistant", "content": answer})  # ← 记忆的关键一行
```

跑:`uv run python -m w3d1_hello_llm.multi_turn`。两个必做实验:
1. 第一轮说「我叫小明」,第二轮问「我叫什么?」→ 答得出。**为什么?** 因为你的代码把上一轮问答塞回了 messages
2. 删掉注释标出的那一行再跑 → 第二轮问同样的问题,它答「不知道」→ **模型自己没有任何记忆,对话记忆 = 你维护的 history 列表**

## 📦 第 4 步:challenge.py——验收挑战(30 分钟)

三道题,都在控制台打印证据:

**挑战 1 · token 对比**:同一句话,中文英文各查一次 usage,对比 prompt_tokens。提示:请求里**不加 system**(控制变量,只放一条 user 消息),「我爱编程」vs「I love programming」,打印两组 usage 数字,亲手验证「中文按字计、英文按词计」的差异。

**挑战 2 · 截断证据**:max_tokens=5 发一个「讲个故事」的请求,打印 `finish_reason`——应等于 `"length"`,这就是被截断的官方证据。

**挑战 3 · 优雅报错**:把 api_key 故意改错,用 `try/except httpx.HTTPStatusError` 捕获,打印「401:API Key 无效,检查 .env」而不是甩一堆堆栈。并记下三个状态码的意思:`401` key 错 / `404` base_url 拼错(常见:漏了 `/v1`)/ `429` 限流或额度用完。
