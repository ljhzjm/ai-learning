## 🎯 先懂 5 个概念(10 分钟)

| 概念 | 一句话解释 |
|---|---|
| **Redis 是什么** | 内存键值数据库(key-value),断电丢数据,所以叫"缓存" |
| **5 大数据类型** | 字符串(string)/哈希(hash)/列表(list)/集合(set)/有序集合(zset)。今天学前两个 |
| **字符串** | 最基础:`SET k v` / `GET k`;值是文本,数字能 `INCR` 自增(计数器/限流靠它) |
| **哈希** | 一张"字段表":`HSET user:1 name 张三 age 20`,一个 key 存多个字段(对象) |
| **TTL 过期** | `EXPIRE k 30` 后 30 秒 key 自动消失。缓存必须设 TTL——否则内存被过期数据占满 |

新建 `redis_basics.py`(项目根目录,练完不入库也行),逐段敲:

```python
import redis, time

r = redis.Redis(host="localhost", port=6379, db=0, decode_responses=True)
# decode_responses=True:返回 str。不加这个,返回的是 bytes(b'xxx')——最经典的新手坑!

# ① 字符串:SET / GET / INCR(计数器)
r.set("greeting", "hello redis")
print(r.get("greeting"))                 # hello redis
r.incr("counter")                        # 不存在当 0 处理,变成 1
r.incr("counter")                        # 2
print(r.get("counter"))

# ② 哈希:HSET / HGETALL(存对象)
r.hset("todo:1", mapping={"title": "学 Redis", "done": "0", "priority": "2"})
print(r.hgetall("todo:1"))               # {'title': '学 Redis', 'done': '0', 'priority': '2'}
print(r.hget("todo:1", "title"))         # 学 Redis

# ③ 过期:EXPIRE / TTL
r.expire("greeting", 30)                 # 30 秒后自动消失
print(r.ttl("greeting"))                 # 剩余秒数(刚设完约 29~30)
time.sleep(1)
print(r.ttl("greeting"))                 # 减 1 了。TTL=-2 表示 key 已不存在
```

## 🗄️ 第 2 步:给 GET /todos 加缓存(40 分钟)

用业界标准的 **cache-aside(旁路缓存)**模式:

```
请求来 → 先问 Redis → 命中直接返回(快)
                    ↘ 未命中 → 查 PG → 把结果写进 Redis(带 TTL)→ 返回
写操作(POST/PUT/DELETE)→ 直接删 Redis 里的缓存 key → 下次读时重建
```

**1. settings 加 Redis 地址**(`config.py` 加一行 + `.env` 加 `REDIS_URL=redis://localhost:6379/0`,`.env.example` 同步):

```python
redis_url: str = "redis://localhost:6379/0"
```

**2. `db.py` 末尾加 Redis 连接**(模块级建一次,连接池复用):

```python
import redis

redis_client = redis.Redis.from_url(settings.redis_url, decode_responses=True)
```

**3. `main.py` 改 `GET /todos`**——先查缓存,未命中查库写缓存:

```python
import json
import redis as redis_lib        # 别和参数名/变量名撞了

@app.get("/todos", response_model=list[TodoOut])
def list_todos(db: Session = Depends(get_db)):
    try:
        cached = redis_client.get("todos:list")
    except redis_lib.RedisError:
        cached = None            # Redis 挂了不崩接口,直接降级查库(生产标准做法)
    if cached is not None:
        return json.loads(cached)
    todos = db.query(Todo).all()
    payload = [{"id": t.id, "title": t.title, "done": t.done,
                "created_at": t.created_at.isoformat(), "priority": t.priority}
               for t in todos]
    redis_client.setex("todos:list", 30, json.dumps(payload))   # 缓存 30 秒
    return payload
```

要点:
- `setex(key, 秒数, 值)` = SET + EXPIRE 一步到位,缓存**必须带 TTL**;
- 缓存的是**JSON 字符串**,不是 Python 对象;datetime 要 `isoformat()` 才能 json 序列化(试试直接 json.dumps 会报什么);
- try/except 兜住 Redis 连接错误 = **降级模式**:缓存挂了服务照常,只是慢一点。这是面试常问点。

**4. 三个写操作(POST/PUT/DELETE)各加一行失效缓存**——函数里改完库、return 之前:

```python
redis_client.delete("todos:list")     # 数据变了,缓存作废,下次读重建
```

**5. 验证缓存真的生效**(两条命令对比):

## 🚦 第 3 步:10 行令牌桶限流(40 分钟)

**为什么限流?** API 公开后,谁都能写脚本狂刷你接口,PG 会被打爆。限流 = 给每个调用者发"令牌",请求来了必须领到令牌才能进,令牌按固定速度补充。

**令牌桶模型**:桶容量固定(比如 10 个),每秒补充固定数量(比如 2 个);请求进来拿 1 个令牌,桶空了就拒绝(429)。

在 `main.py` 里加这个依赖函数(**核心就 10 来行,逐行读懂**):

```python
import time

def allow_request(key: str, capacity: int = 10, rate: float = 2) -> bool:
    now = time.time()
    tokens, ts = redis_client.hget(key, "tokens"), redis_client.hget(key, "ts")
    tokens = float(tokens if tokens is not None else capacity)   # 新桶 = 满的
    ts = float(ts if ts is not None else now)
    tokens = min(capacity, tokens + (now - ts) * rate)           # 按速率补充,不超过容量
    redis_client.hset(key, mapping={"tokens": tokens - 1, "ts": now})
    redis_client.expire(key, 60)                                 # 闲置 60 秒回收桶
    return tokens >= 1                                            # 补完还不满 1 个 → 拒绝
```

然后挂成 FastAPI 依赖(给**全部接口**限流,按客户端 IP 分桶):

```python
from fastapi import HTTPException, Request

def rate_limit(request: Request):
    try:
        ok = allow_request(f"rl:{request.client.host}")
    except redis_lib.RedisError:
        return                       # Redis 挂了放行(fail-open,生产标准做法)
    if not ok:
        raise HTTPException(429, "Too Many Requests")

app = FastAPI(...)                    # 挂哪里?见下

app.include_router(router, dependencies=[Depends(rate_limit)])
```

(你的项目路由可能是 `@app.get(...)` 直接写在 main.py——那样就逐个装饰器加 `dependencies=[Depends(rate_limit)]`,或者给 app 挂全局依赖。先看看自己项目长什么样再决定。)

**验证限流生效**——把 capacity 临时调小(比如 2),重启服务,连打 5 个请求:

```powershell
for /l %i in (1,1,5) do curl -s -o nul -w "%{http_code} " http://127.0.0.1:8000/todos
```

预期看到一串 `200 200 429 429 429`(前两个领到令牌,后面桶空了)。等几秒再打,又变 200——**令牌在自动补充**。这是今天最爽的一个瞬间。

要点:
- `request.client.host` = 客户端 IP,每个 IP 一个桶,谁刷封谁;
- Redis 挂时 fail-open(放行)——限流服务不该比业务更脆弱;
- 桶状态存在 Redis 哈希里,`hget/hset` 两个字段,10 行装下整个算法。
